# 附加质量法与箱体估算

## 测量条件

- 无配重与配重必须使用同一单元、同一姿态、同一支撑、同一线材和同一电平。
- 优先把盆架刚性固定、振膜轴线水平；如果振膜朝上，也要让前后两组保持朝上并确保后部通气孔不被桌面堵住。
- 手持结果只能作交叉验证；用刚性支架的数据作为设计主值。
- 配重须准确称量、均匀固定且尽量无磁。胶带/橡皮泥本身也计入质量。
- 合适的加重后频移是 `Fs` 下降约 20%–30%。

`Dd` 从一侧悬边宽度的中点，经圆心量到另一侧悬边宽度的中点：

```text
Sd = π × Dd² / 4
```

如果厂家给出可信 `Sd`，优先使用厂家 `Sd`，不要把盆架外径或硬锥盆直径当作 `Dd`。

## 本地临时螺丝记录

```text
30颗 = 0.04市斤 = 20g
1颗  ≈ 0.667g
4颗  ≈ 2.67g
12颗 ≈ 8.00g
16颗 ≈ 10.67g
```

该记录来自低分辨率厨房秤。重量误差会近似同比传递到 `Mms` 和 `Vas`；正式结果应使用 0.1g 或更高精度电子秤称总配重。

## 计算

对每一对自由空气/配重结果分别计算：

```text
Mms = M_added / ((Fs / Fs_added)² - 1)
Cms = 1 / ((2πFs)² × Mms)
Vas = ρ × c² × Sd² × Cms
Bl  = √(2πFs × Mms × Re / Qes)   # 仅在 Re、Qes可靠时
```

单位：质量 kg，`Cms` 为 m/N，`Sd` 为 m²；常温可用 `ρ=1.204kg/m³`、`c=343.2m/s`。

运行技能脚本：

```bash
python3 scripts/ts_added_mass.py \
  --pair 58.982,43.712 \
  --pair 59.002,44.029 \
  --mass-g 10.67 \
  --sd-cm2 147.4 \
  --qts 0.75 \
  --volumes 10,12,15,18,20
```

脚本逐对输出频移、`Mms/Cms/Vas`，然后按平均值模拟密闭箱。

## 结果取舍

- 每个状态两次 `Fs` 差异目标小于 0.5%；略超出时可用于范围估计，但不要给虚假的高精度。
- 如果手持与刚性支架得到不同结果，以刚性支架为主，手持组用于估计姿态/支撑敏感度。
- `Vas` 与厂家接近不代表全部参数合格；同时比较 `Fs/Qts/Re/Le`。
- 老化、维修、温度和悬挂预压会改变 `Fs/Q`；明确测量状态，不用厂家值覆盖实测值。

## 密闭箱

```text
Qtc = Qts × √(1 + Vas/Vb)
Fc  = Fs  × √(1 + Vas/Vb)
```

`Vb` 是净容积，必须扣除单元、加强筋、分频器和其他结构。脚本同时计算二阶高通近似的 `F3` 与响应峰值。

高 `Qts` 单元无法通过有限密闭箱得到低于自身 `Qts` 的 `Qtc`。桌面、靠墙或墙角会进一步抬升中低频，因此箱体选择要结合摆位和 DSP：

- 有低音炮：可选较小密闭箱，并在约 70–90Hz 高通后实测衔接。
- 无低音炮：略大密闭箱只能温和改善下潜；不要用大幅低频 EQ 强迫小口径单元输出超低频。
- `Qts` 偏高、`Vas` 未可靠测得或缺乏倒相模拟时，不要贸然推荐倒相箱。

阻抗/T/S 只解决低频机电模型。最终两/三分频音箱仍需测量各单元声压、相位、失真和指向性，并验证实际分频、极性、延时及箱体泄漏。
