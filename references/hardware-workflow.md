# UMC202HD + 47Ω 阻抗盒工作流

## 已验证的本地硬件

```text
UMC202HD PHONES 左声道 -> 阻抗盒输出激励
Input 1 / L             -> 参考输入（采样电阻前）
Input 2 / R             -> 测量输入（DUT 两端）
R_SENSE                 -> 47.00Ω 标称，优先填万用表实测值
R_REF                   -> 10.00Ω
R_INPUT                 -> 20,000Ω
R_LEADS                 -> 0.000Ω（完成短路校准后）
```

UMC202HD：两路均用 `LINE`，PAD 关闭，+48V 关闭，DIRECT MONITOR 关闭。校准后不要改变 Gain 1、Gain 2、PHONES、OUTPUT、输入模式、USB 口或线材。

安全边界：只测无源器件。不要把功放输出接入声卡输入。拆接 DUT 前停止扫频并降低输出。

## REW 推荐起始设置

| 项目 | 值 |
|---|---|
| 输入/输出设备 | UMC202HD 192k |
| 采样率 | 44.1kHz |
| 缓冲区 | 32k（稳定时保持） |
| 输出通道 | L |
| 参考输入 | L / Input 1 |
| 测量输入 | R / Input 2 |
| 虚拟平衡输入 | 关闭 |
| 32位视为24位 | 开启 |
| 类型/方法 | 阻抗 / 扫频 |
| 范围 | 20Hz–20kHz |
| 长度/重复 | 512k / 2 |
| 噪声过滤 | Filter medium |
| 起始电平 | -30dBFS；检查电平后才谨慎提高 |

若出现 `excessive clipping`，先降低扫频电平或声卡输入增益；不要关闭削波保护来强行完成测量。

## 三步校准与验证

发生以下变化后，清除旧校准并依次重做：采样电阻、阻抗盒、输入/输出声道、声卡/USB口/驱动、采样率、旋钮、线材、转接头或焊接维修。

1. **开路**：DUT 端完全悬空。测量/参考比例宜在约 89%–112% 且全频平稳。最近一次 93.18% 可接受。
2. **短路**：在 DUT 最终端子牢固短接。测量输入必须明显低于参考输入。若两者接近，检查 Input 1/2 是否反接、短路位置及输出 L/R。
3. **10Ω参考**：接 10.00Ω 已知电阻，执行参考校准。
4. **独立验证**：把另一只已知电阻当普通 DUT。当前阻抗盒历史 47Ω 验证为约 47.30Ω、全频平直、相位接近 0°。低阻单元最好再用 2–5Ω 精密电阻验证。

参考校准曲线接近 10Ω 只是校准目标，不能单独证明整个量程准确。

## 普通扬声器测量

1. 盆架刚性支撑并离开桌面，后部通气孔保持开放；线材固定且不牵拉端子。
2. 点击“检查电平”，确认无削波。
3. 连续完成 2–3 次独立扫频；命名包含单元、状态、姿态和序号。
4. 记录温度、支撑、朝向、`Dd/Sd`、配重、输入增益和扫频电平。
5. 仅更换 DUT、支撑或配重，无需重做电气校准；但 T/S 的无配重和配重测量必须保持同一机械姿态。

## 故障判断

| 现象 | 优先检查 |
|---|---|
| 短路时测量与参考几乎相同 | Input 1/2、DUT 端是否真正短路 |
| 两路均约 -60dBFS | PHONES、输出声道、Tip/Ring、测试信号 |
| 整条曲线按比例漂移 | 旋钮、接触不良、校准状态 |
| 仅谐振峰变化 | 支撑、桌面耦合、线材牵拉、环境振动 |
| 配重曲线有窄尖峰 | 配重移动/不对称、胶带松动、钢件受磁力 |
| 已知电阻不平或相位偏离0° | 校准、焊点、接线柱、线材或通道 |

需要排查阻抗盒时，断电后用万用表低阻档测导通并摇动线材/焊点；扣除表笔电阻后，普通导线不应额外增加约 0.1–0.3Ω 以上且读数不得跳变。
